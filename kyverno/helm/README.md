# Kyverno Helm Chart
Com a instalacao do Kyverno via Helm Chart aqui estao os valores para usar.

Eles foram gerados com o comando:

- Ultima versao
```shell
helm search repo kyverno/kyverno -l
```
- Pegar os valores:
```shell
helm show values kyverno/kyverno
```
